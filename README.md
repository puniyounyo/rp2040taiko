
RP2040-Zeroを使用したNintendo Switch向け太鼓コントローラー変換基板です。

## 主な機能

- SNES（SFC）純正コントローラー対応
- ピエゾセンサー4ch入力対応
- Nintendo Switch / PCモード切替
- OLED表示対応
- EEPROM設定保存対応
- Webブラウザによる設定変更・モニタリング対応

## 変更履歴

| Version | 主な変更内容 |
|----------|-------------|
| V0.1 | 初版リリース。SNESコントローラー入力、ピエゾ4ch入力、Switch/PCモード、OLED表示、EEPROM保存機能を実装。 |
| V0.2 | 判定パラメータを見直し、誤検知低減とレスポンス向上を実施。全体的な安定性を改善。 |
| V0.3 | Webモニター機能を追加。ヒット情報のシリアル出力に対応し、ブラウザから動作確認が可能に。判定ロジックおよびボタン配置を調整。 |
| V0.4 | Web経由での感度調整・設定保存機能を追加。RAWデータ出力、キャリブレーション機能、高精度判定ロジック（PairDelayGate）を実装。 |

- Waveshare RP2040-Zero

- SSD1306 OLED（任意）
- USB Type-Cケーブル

## GPIO割り当て

### SNESコントローラー

| 信号 | GPIO |
|--------|--------|
| LATCH | GP0 |
| CLOCK | GP1 |
| DATA | GP2 |
| VCC | 3.3V |
| GND | GND |

---

### OLED（SSD1306 / I2C）

| OLED | GPIO |
|--------|--------|
| SDA | GP4 |
| SCL | GP5 |
| VCC | 3.3V |
| GND | GND |

※OLEDは任意です。未接続でも動作します。

---

### ピエゾセンサー

| センサー | ADC | GPIO | 役割 |
|----------|-----|------|------|
| CH0 | ADC0 | GP26 | 左カ |
| CH1 | ADC1 | GP27 | 左ドン |
| CH2 | ADC2 | GP28 | 右ドン |
| CH3 | ADC3 | GP29 | 右カ |

---

### オンボードLED

| 機能 | GPIO |
|--------|--------|
| NeoPixel | GP16 |

動作モードに応じて色が変化します。

| 色 | 状態 |
|------|------|
| 青 | Switchモード |
| 緑 | PCモード |
| 赤 | 設定モード |

## ボタン割り当て

### 太鼓 → Nintendo Switch

| 太鼓入力 | Switch入力 |
|----------|------------|
| 左カ (CH0) | ZL |
| 左ドン (CH1) | Lスティック押し込み |
| 右ドン (CH2) | Rスティック押し込み |
| 右カ (CH3) | ZR |

## 電源

RP2040-ZeroのUSB Type-C端子より給電します。

- 動作電圧：5V（USB）
- ロジック電圧：3.3V
- OLEDおよびSNESコントローラーは3.3Vで動作

---

## 初回動作確認

1. ファームウェアを書き込む
2. USB接続する
3. OLEDにモード表示されることを確認
4. 太鼓を叩き各センサーが反応することを確認
5. Webモニターへ接続
6. `RAWON` で生データ確認
7. 感度調整後 `SAVE` で保存

---

## Webモニターコマンド

### 現在設定取得

```text
GETS
```

### 感度変更

```text
SENS:0=130:1=100:2=100:3=130
```

### EEPROMへ保存

```text
SAVE
```

### RAWデータ出力開始

```text
RAWON
```

### RAWデータ出力停止

```text
RAWOFF
```

## 注意事項

- ピエゾ配線はできるだけ短く施工してください。
- 配線の引き回しによっては誤検知の原因となります。
- ピエゾ配線はホットボンド等で固定し、断線対策を推奨します。
- 感度設定は設置環境によって最適値が異なります。
- V0.4ではWebブラウザからリアルタイム調整が可能です。
