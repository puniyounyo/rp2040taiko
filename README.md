# RP2040 Taiko Controller

RP2040-Zeroを使用した Nintendo Switch / PC 対応の太鼓コントローラー変換基板です。

## 主な機能

- SNES（SFC）純正コントローラー対応
- ピエゾセンサー4ch入力対応
- Nintendo Switchモード対応（ポッ拳コントローラー互換）
- PCキーボードモード対応
- OLED表示対応（任意）
- EEPROM設定保存対応
- Webモニター対応
- Web経由の感度調整対応
- RAWデータ出力対応
- 自動キャリブレーション対応

---

## GPIO割り当て

### SNESコントローラー

| 信号 | GPIO |
|--------|--------|
| LATCH | GP0 |
| CLOCK | GP1 |
| DATA | GP2 |
| VCC | 3.3V |
| GND | GND |

### OLED（SSD1306）

| OLED | GPIO |
|--------|--------|
| SDA | GP4 |
| SCL | GP5 |
| VCC | 3.3V |
| GND | GND |

### ピエゾセンサー

| センサー | GPIO | 役割 |
|----------|--------|--------|
| CH0 | GP26(ADC0) | 左カ |
| CH1 | GP27(ADC1) | 左ドン |
| CH2 | GP28(ADC2) | 右ドン |
| CH3 | GP29(ADC3) | 右カ |

## 操作方法

### 通常起動

電源投入時にSTARTボタンを押していない場合

- Switchモードで起動
- NeoPixel：青

### PCモード

電源投入時にSTARTボタンを押しながら起動

- キーボードエミュレーションモード
- NeoPixel：緑

---

## 設定モード

SELECTボタン短押し

- OLED上でパラメータ設定
- EEPROM保存対応
- NeoPixel：赤

---

## GOD CALIB（神自動キャリブレーション）

SELECTボタンを1秒以上長押し

- 自動キャリブレーション開始
- NeoPixel：黄

各センサーを20回程度叩くことで、

- 感度（Threshold）
- クロストークガード
- 左右ガード値

を自動算出します。

完了後は自動的にEEPROMへ保存されます。

## Webモニターコマンド

### 設定取得

```text
GETS
```

### 設定変更

```text
SENS:0=80:1=160:2=160:3=80
```

### EEPROM保存

```text
SAVE
```

### RAWデータ出力開始

```text
RAWON
```

### RAWデータ出力停止

```text
RAWOFF
```

## パラメータ一覧

| No | 名称 | 内容 |
|----|------|------|
| 0 | L_EDGE | 左カ感度 |
| 1 | L_FACE | 左ドン感度 |
| 2 | R_FACE | 右ドン感度 |
| 3 | R_EDGE | 右カ感度 |
| 4 | FACE_INTV | 面入力ガード |
| 5 | EDGE_INTV | 縁入力ガード |
| 6 | CROSS_IG | 面⇔縁クロストーク抑制 |
| 7 | HOLD_MS | 押下保持時間 |
| 8 | FACE_SGL | 面自己抑制 |
| 9 | EDGE_SGL | 縁自己抑制 |
| 10 | FACE_LR | 左右面ガード |
| 11 | EDGE_LR | 左右縁ガード |
