# RP2040 Taiko Controller

RP2040-Zeroを使用したNintendo Switch向け太鼓コントローラー変換基板です。

## 主な機能

- SNES（SFC）純正コントローラー対応
- ピエゾセンサー4ch入力対応
- Nintendo Switch / PCモード切替
- OLED表示対応
- EEPROM設定保存対応
- Webブラウザによる設定変更・モニタリング対応

## 変更履歴

| Version | 主な変更内容 |
|----------|-------------|
| V0.1 | 初版リリース。SNESコントローラー入力、ピエゾ4ch入力、Switch/PCモード、OLED表示、EEPROM保存機能を実装。 |
| V0.2 | 判定パラメータを見直し、誤検知低減とレスポンス向上を実施。全体的な安定性を改善。 |
| V0.3 | Webモニター機能を追加。ヒット情報のシリアル出力に対応し、ブラウザから動作確認が可能に。判定ロジックおよびボタン配置を調整。 |
| V0.4 | Web経由での感度調整・設定保存機能を追加。RAWデータ出力、キャリブレーション機能、高精度判定ロジック（PairDelayGate）を実装。 |
